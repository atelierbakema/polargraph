## What is it?

The Polargraph Controller is a little app that we use to specify the size of the machine, the sprockets, and the motor driver types.

You can see a preview of the machine, and lay out your artwork on it, visualising many aspects of the drawing.

## Run it

There are precompiled binary versions of the controller [in the main software bundle.](https://github.com/euphy/polargraphcontroller/releases/latest). If those don't work (Processing is a little fickle), then you can [compile and run it from source](https://github.com/euphy/polargraph/wiki/Running-the-controller-from-source-code) fairly easily.
